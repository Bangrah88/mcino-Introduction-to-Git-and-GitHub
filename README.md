# github-final-project

## Description
This project is a simple interest calculator that calculates the simple interest based on:
- Principal amount
- Annual interest rate
- Time period in years

## Formula
Simple Interest is calculated using the formula:

simple interest = (p * t * r) / 100

Where:
- `p` = Principal amount
- `t` = Time period in years
- `r` = Annual rate of interest

## Input
The program accepts the following inputs:
- `p` → Principal amount
- `t` → Time period in years
- `r` → Annual rate of interest

## Output
The program returns:
- Simple Interest

## Example
Input:
p = 1000
t = 2
r = 5

Output:
simple interest = 100
